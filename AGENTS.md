# Project agent guide

This repository is a Copier template; files in `template/` belong to generated
projects. See [README.md](README.md) for the repository structure and workflow.

## Conventions

- Do not maintain a changelog for this repository: do not update
  `CHANGELOG.md` or add changelog fragments for development work.
- Generated projects may retain their own changelog and release tooling.

## Validation

- Run `uv run pytest` for template and tooling changes.
- Run the relevant pre-commit hooks for changed files.
